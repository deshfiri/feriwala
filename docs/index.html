DEVELOPER DOCUMENTATION

The complete map of Banij

Banij is an ERP for wholesale and dropshipping in Bangladesh. Partners buy from a central catalogue or sell it on their own storefronts; suppliers feed the catalogue; Banij is the merchant of record and keeps the money straight. This is the map of the whole system for a developer joining the project.

How to read these pages

  • Module pages share one shape: purpose, where it lives, terms, data model, states, actions, entry points, permissions, money effects, configuration, gotchas, how-tos, testing, related modules.
  • Paths are relative to the repository root. Names (classes, routes, permissions, enum cases) were taken from the code, not from memory.
  • The live OpenAPI references are served by the running app at /docs/mobile and /docs/storefront. The files docs/api/mobile.md and docs/api/storefront.md feed them — edit those, not these pages, to change the API text.
  • The original specification is requirements.txt (cited as §number); approved decisions are in requirements/04-decisions.md (cited as D-number).
